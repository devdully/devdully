## selected projects

### [networked battleship](https://github.com/devdully/networked-battleship)

two-player battleship over the network, plus a single-player mode against the computer. built in java with javafx and a central game server.

### [png hidden files](https://github.com/devdully/png-hidden-files)

hide any file inside a png image and recover it later without changing how the image looks. built with c command-line tools and a python aiohttp web interface.

### [threaded http server](https://github.com/devdully/threaded-http-server)

a static-file http/1.1 server written in c with posix sockets and pthreads, including request parsing, file streaming, and concurrent connections.

### [campus navigator](https://github.com/devdully/campus-navigator)

a c++ route planner built on real openstreetmap data that uses dijkstra's algorithm to find shortest walking routes.

### [15-puzzle solver](https://github.com/devdully/15-puzzle-solver)

solves the 4×4 sliding-tile puzzle with bfs, iterative deepening, a*, and ida*, with benchmarks comparing time and memory usage.

### [blackjack](https://github.com/devdully/javafx-blackjack)

a single-player blackjack game built with java and javafx, with bankroll management, betting, dealer logic, blackjack payouts, and hand evaluation.
